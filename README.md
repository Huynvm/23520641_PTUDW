# Giới thiệu bản thân - Personal Profile Webpage

Đây là một trang web đơn giản nhằm **giới thiệu bản thân**, trình bày thông tin cơ bản, sở thích, mục tiêu cá nhân và cung cấp một **form liên hệ** để người khác có thể gửi tin nhắn và giao lưu.

---

## Nội dung trang web

1. **Giới thiệu bản thân**
   - Ảnh cá nhân
   - Thông tin cơ bản:
     - Tên
     - Năm sinh
     - Chuyên ngành
   - Sở thích
   - Món ăn yêu thích
   - Giải trí
   - Trò chơi
   - Bài hát yêu thích

2. **Mục tiêu cá nhân**
   - Hiển thị bảng các mục tiêu, thời hạn hoàn thành và trạng thái (checkbox)

3. **Form liên hệ**
   - Họ và tên
   - Email
   - Tin nhắn
   - Giới tính (Nam/Nữ)
   - Sở thích (checkbox)
   - Ngành (dropdown)
   - Nút gửi
